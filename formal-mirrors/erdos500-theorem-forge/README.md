# Erdős #500 — Turán (3,4) research program

This directory is a **transitional research-program mirror** for work on the Turán (3,4) problem. The four theorem-bank files preserve a reconstructed 76-record mathematical program; they are not part of the repository's 79-declaration Lean corpus unless separately represented under `theorems/`.

## Program scale

The reconstructed surface contains **76 distinct records**, including:

- 43 results proved in the packet;
- 7 finite exhaustive results;
- 18 explicit targets;
- exact finite witnesses and classifications;
- a sharp bound;
- an equivalence;
- an analytic result;
- a negative theorem.

The records are stored in:

- `bank-001-019.md`
- `bank-020-038.md`
- `bank-039-057.md`
- `bank-058-076.md`

A second mirror, `../erdos500-turan34/`, preserves machine-readable package data for the same broader program.

## Mathematical layers

The program develops several connected viewpoints on the problem:

- complement-covering duality;
- finite-to-global density transfer;
- deletion-excess identities and plateau rigidity;
- pair-codegree bookkeeping;
- four- and five-set waste/excitation identities;
- exact small covering values;
- cyclic pair-rotor constructions;
- one-point extension analysis;
- graph-generated cover classification;
- independent-triple repair;
- an integral-gap reformulation;
- rooted collision identities.

The value of the bank is not that all 76 records have the same authority. It is that theorem, finite computation, target, negative theorem and conditional reduction are preserved separately inside one coherent mathematical program.

## Repository status

Erdős #500 has outgrown a generic theorem bank and should ultimately have one dedicated problem repository. Until that repository exists, this directory and `../erdos500-turan34/` are research mirrors rather than competing canonical homes.

The parent Turán (3,4) problem remains open; the proved child statements retain their own exact scope regardless of parent-problem status.
